# Rugby Game Scraper

A simple project written to scrape a website containing rugby union data and output as JSON format. 

Designed for my Rugby Union Management Sim game.

## History of the Project
This project was initially written in Python (with the use of AI LLM models heavily). After deciding that I don't want to use ANY AI in any of my projects, I decided to rewrite the project from scratch (and also becuase of a couple of niggling bugs) to remove any AI-generated code and to ensure that I am actually learning during this process - instead of mindlessly using AI code.
